# 📇 Contact Manager App

## 🚀 Features

* Add, Edit, Delete Contacts
* Search Contacts
* API integration using Axios
* Routing using React Router

## 🛠 Tech Stack

* React.js
* Axios
* Tailwind CSS
* JSON Server / Node Backend

## 📦 Installation

```bash
git clone https://github.com/your-username/project-name.git
cd project-name
npm install
npm start
```

## 🌐 API Setup

```bash
json-server --watch db.json --port 3006
```
